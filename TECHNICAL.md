# Техническая документация — Форма регистрации

Учебный проект «Форма регистрации» — статичное клиентское веб-приложение на чистом
HTML/CSS/JS без сборки и зависимостей. Форма (телефон + пароль + подтверждение пароля)
работает полностью в браузере.

---

## 1. Обзор

- **Тип:** статический сайт (SPA-подобная форма, без серверной части)
- **Стек:** HTML5, CSS3, Vanilla JavaScript (ES6), без библиотек и сборщиков
- **Запуск:** открытие `index.html` в браузере; установка не требуется

---

## 2. Структура проекта

```
registration-form/

├── style.css       # все стили и дизайн-токены
```

|------|-----------|

## 3. Технологии и совместимость

- Чистые **HTML5 / CSS3 / JavaScript (ES6+)** — без внешних зависимостей и CDN.

## 4. Взаимодействие `index.html` ↔ `script.js`

Связь обеспечивается через фиксированные `id` элементов. Изменение любого `id`
в одном файле должно сопровождаться изменением в другом.

| `id` | Роль | Использование в JS |
|------|------|--------------------|
| `signupForm` | Форма | `form.addEventListener('submit', …)`, `form.reset()` |
| `phone` | Поле телефона | маска, валидация, фокус |
| `password` | Поле пароля | проверка надёжности и длины |
| `confirmPassword` | Поле подтверждения | сравнение с паролем |
| `submitBtn` | Кнопка «Зарегистрироваться» | блокировка/разблокировка |
| `phoneError` | Сообщение об ошибке телефона | вывод текста ошибки |
| `passwordError` | Сообщение об ошибке пароля | вывод текста ошибки |
| `confirmError` | Сообщение об ошибке подтверждения | вывод текста ошибки |
| `strengthBar` | Полоса индикатора надёжности | ширина и цвет |
| `strengthLabel` | Текст уровня надёжности | «Слабый/Средний/Сильный» |
| `successMessage` | Контейнер toast-уведомления | добавление/снятие класса `.show` |
| `successText` | Текст toast-уведомления | текст «Регистрация прошла успешно!» |

## 5. Логика валидации (`script.js`)

### 5.1. Телефон

**Маска ввода** — `formatPhone(digits)`:

- Пользователь вводит **только цифры**.
- Код страны `+7` подставляется автоматически (ведущая `8` переводится в `7`).
- Прогрессивное форматирование:

```
9          → +7 (9
999        → +7 (999
999123     → +7 (999) 123
9991234567 → +7 (999) 123-45-67
```

**Валидация** — `validatePhone(value)`:

1. Из строки извлекаются только цифры: `value.replace(/\D/g, '')`.
2. Требования:
   - ровно **11 цифр** (`digitsOnly.length === 11`);
   - начинается с `7` или `8` (`startsWith('7') || startsWith('8')`).

**Поведение поля:**

- При фокусе на пустом поле автоматически подставляется `+7`.
- Ошибка «Введите номер в формате +7XXXXXXXXXX (11 цифр)» показывается только когда
  набрано 11 цифр и номер невалиден (чтобы не мешать во время ввода).

### 5.2. Пароль

**Оценка надёжности** — `getPasswordStrength(value)`:

- `score` увеличивается за каждый выполненный критерий:
  - длина ≥ 8 символов;
  - наличие цифры (`/[0-9]/`);
  - наличие спецсимвола (`/[^a-zA-Z0-9]/`);
  - наличие букв в обоих регистрах (`/[A-Z]/ && /[a-z]/`);
- Уровень: `score ≤ 1 → 1` (Слабый), `score ≤ 2 → 2` (Средний), иначе `3` (Сильный).

**Допустимость** — `isPasswordValid(value)`:

```
getPasswordStrength(value) >= 2  &&  value.length >= 8
```

То есть пароль должен быть не короче 8 символов и иметь минимум «Среднюю» надёжность.

**Индикатор** — `updateStrengthUI(value)`:

| Уровень | Ширина | Цвет | Метка |
|--------:|-------:|------|-------|
| 0 | 0% | `#eaeaea` | — |
| 1 | 33% | `#e5484d` | Слабый |
| 2 | 66% | `#f5a623` | Средний |
| 3 | 100% | `#1a7f37` | Сильный |

### 5.3. Подтверждение пароля

**Сравнение** — `doPasswordsMatch(password, confirm)`:

```js
return password === confirm && confirm.length > 0;
```

- Сравнение **регистрозависимое** (строгое), по эталону.
- Оба поля должны быть заполнены (`confirm.length > 0`).

> ⚠️ Известный исправленный баг: ранее сравнение шло через `toLowerCase()`,
> из-за чего `abc` и `ABC` считались совпадающими. Исправлено на `===`.

### 5.4. Общее состояние формы

`isFormValid()` — суммарная проверка:

```js
phoneOk && passwordOk && confirmOk
```

`updateSubmitButtonState()` — кнопка `submitBtn.disabled = !isFormValid()`,
плюс визуальное состояние (прозрачность и курсор).

## 6. Обработчики событий

| Событие | Элемент | Действие |
|---------|---------|----------|
| `focus` | `phone` | Подставляет `+7`, если поле пустое |
| `input` | `phone` | Применяет маску `formatPhone`, валидирует номер |
| `input` | `password` | Обновляет индикатор, валидирует пароль, пересчитывает подтверждение |
| `input` | `confirmPassword` | Проверяет совпадение паролей |
| `submit` | `signupForm` | `preventDefault()`; при валидной форме — уведомление и сброс |

## 7. Уведомление об успешной регистрации (Toast)

При успешной отправке формы:

1. `showSuccessToast()` — устанавливает текст и добавляет класс `.show` к `#successMessage`;
2. toast появляется сверху экрана (fixed, по центру);
3. автоматически скрывается через **3500 мс** (`setTimeout`);
4. `resetForm()` — сбрасывает форму: поля, ошибки, индикатор надёжности, состояние кнопки.

Toast реализован как фиксированный элемент `position: fixed; top: 20px`,
с плавным переходом `opacity` и `transform` (выезд сверху).

## 8. Стилизация (`style.css`)

**Дизайн-токены:**

| Параметр | Значение |
|----------|----------|
| Фон страницы | градиент `#eef2ff → #f8fafc → #eef6f1` |
| Карточка | `#ffffff`, радиус `20px`, тень `0 24px 60px rgba(31,41,90,.12)` |
| Акцент (кнопка, фокус) | `#6366f1` / `#4f46e5` (индиго) |
| Ошибка | `#e5484d` |
| Успех (toast) | `#16a34a` |
| Плейсхолдер | `#9ca3af` (серый) |
| Ширина карточки | `max-width: 380px` |

**Ключевые компоненты:**

- `.form-head` — шапка с логотипом, заголовком и подзаголовком;
- `input` — закруглённые поля с `focus-ring` (box-shadow) при фокусе;
- `.strength-meter` — секционный индикатор (4 зоны) поверх полосы `.strength-bar`;
- `button` — градиентная кнопка с hover/active-состояниями;
- `.toast` / `.toast.show` — уведомление (скрытое/видимое состояние).
